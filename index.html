Control the room from one screen

What it does

Per-screen control

Brightness, presets and blackout for every screen on every controller, from a slider and a couple of taps.

Power

On/off per power unit with plain-language status, plus optional independent control of up to 6 named relays.

Presets

Save a whole look — brightness, presets, blackout, OBS scene — across every device, and recall it in one tap.

Scheduler

Power on/off or apply a preset on a daily or weekly schedule, with a shutdown countdown you can extend.

Live, everywhere

Every open screen reflects the same state within seconds — no refresh, no "did that actually work?"

Locked down if you want it

An optional shared password gates the entire panel — nobody without it sees so much as read-only state.

Built for the AV network, not the internet

eXcontrol assumes a dedicated, trusted LAN — the same assumption almost every product in this category makes. Plain HTTP, no accounts to manage, one shared password if you want a lock on the door.
