Mellemleddet, der taler alle sprogene

Frontenden er kun toppen af isbjerget. Bag den kører en motor, der kender hver enheds protokol, sekvenserer strømmen sikkert og deler live status med alt på netværket.

Hvorfor det betaler sig for partnere

Mindre tid på protokoller og supportopkald. Mere tid på installationer, der sælger.

⚡

Hurtigere levering

Enhederne findes automatisk på netværket — opsætning på under 5 minutter. Ingen egen driverudvikling pr. producent.

🛡️

Færre fejl hos kunden

Slutkunden trykker på en scene — ikke i en LED-controllers web-UI. Sikker, sekventeret strøm og ærlig status på skærmen.

🔌

Ét API i stedet for fem

Grupper, skemaer og scener i ét programmørvenligt API. Jeres system taler med eXcontrol — eXcontrol taler med resten.

✅

Testet og godkendt

Alt, der kommer ind i eXcontrol, er testet og godkendt af Expromo — mod rigtig hardware, strømsvigt og nedbrud.

📡

Live overalt

Samme live status på touchskærm, tablet, mobil og API — alle på netværket ser det samme, i samme øjeblik.

🔄

Altid opdateret

Versionsstyrede opdateringer kan nå alle installationer — når kunden ønsker det, ikke før.

Sådan fungerer det

Partneren gør det, partneren er god til. eXcontrol klarer resten.

Opsæt presets i controlleren

Lav og navngiv presets i NovaStar H-Series eller COEX, som I plejer.

eXcontrol læser dem tilbage

Presets, navne og layout læses automatisk — og vises som billeder, kunden forstår med det samme.

Kunden eller systemet trykker

Fra touchskærm, tablet, Companion eller API. Status flyder tilbage i realtid.

Kører der, hvor I har brug for det

Windows

Standard .exe-installer. Starter med Windows, opdaterer sig selv efter godkendelse.

Linux · Raspberry Pi

Debian-baseret — en Raspberry Pi med touchskærm bliver en færdig kontrolenhed. Kører som service med automatisk genstart.

Det er ikke en Crestron-killer. Det er værktøjet, der gør LED-installationer så nemme at integrere, som de kan blive — fordi Expromo tager det tunge løft med protokoller og API'er.
